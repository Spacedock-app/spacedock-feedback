# SpaceDock feedback

This is the public place for bug reports, questions and feedback about **SpaceDock**, a local-first browser extension for Brave and Chrome that turns browser windows into Spaces with lasting Groups of tabs.

SpaceDock is in **closed alpha**. This repository does not contain the extension's source code, and access to it does not give you the test package. If you are a tester, the package you received has the installation steps and a safe first trial.

## Report something
- **A bug:** [Report a bug](../../issues/new?template=bug-report.yml)
- **A question, an idea or an impression:** [Question or feedback](../../issues/new?template=feedback.yml)
- **Something you would rather not make public** (a screenshot with private pages, a file, a data-loss story with details): write to **spacedock.project@gmail.com**.

## Please keep it private-safe
Everything in this repository is public, attachments included. Do **not** post:
- a full backup (it contains the addresses and titles of your pages),
- private URLs, tokens or personal information,
- screenshots that show pages you would not want strangers to see.

If in doubt, send it by email instead.

## What helps most
- The SpaceDock version (`brave://extensions` → SpaceDock) and your browser version.
- What you did, what you expected, what happened.
- If data seemed to go missing: whether **Trash**, **Undo** or **History** brought it back.
- Optionally: the result of **Tools → Backup & import → Check data integrity** (it lists counts and short names, no full addresses).
