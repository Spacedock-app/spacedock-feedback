# Security

SpaceDock keeps all data in your browser and has no server or account. A security problem here would be something like data exposed to a page, a permission used beyond what it needs, or a way to make SpaceDock change or delete data without the user asking.

Please report such a problem **by email, not as a public issue**: spacedock.project@gmail.com

Describe what you saw and the SpaceDock version. Please do not publish steps to exploit it, and do not send a full backup or private addresses.
